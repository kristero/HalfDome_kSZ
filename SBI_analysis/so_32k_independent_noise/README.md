# Independent-noise SO mocks: two-parameter and nine-parameter datasets

The default remains 32768 rows per dataset, baseline deproj0 only. See
`VALIDATION.md` and `validation_plots/` for the noise and painter audit.
`MOCK_AUDIT_EXPLAINED.md` explains the threaded-painter/beam fixes, every check,
the larger-run setup, and the new `sobol_plots/` distributions in detail.

## What to generate

Two separate sets of **32,768 simulations each** (65,536 total):

- `two_param`: vary P0 and beta. Fix the other seven parameters to Battaglia12.
- `nine_param`: vary all nine Battaglia pressure parameters.

Both use **masked SO baseline, deprojection 0 only**, the same HalfDome lightcone,
cosmology, 2 arcmin signal beam, and mask. Each simulation has two independent
Gaussian noise splits; no noise split seed is reused in any other row or dataset.

The masked clean reference spectrum is also saved from the same signal map. It
is useful for later MOPED/diagnostic work and is not another noisy implementation.
No goal/deproj2 spectra are generated by default; see the configuration below.
No FITS maps are saved. Noise maps exist only in RAM.

## Parameter tables and priors

Both CSVs have the same nine-column order:

| Column | Parameter | Lower bound | Upper bound | Battaglia12 |
|---|---|---:|---:|---:|
| 1 | P0 | 1.81 | 34.39 | 18.1 |
| 2 | xc | 0.1491 | 0.8449 | 0.497 |
| 3 | beta | 3.48 | 5.22 | 4.35 |
| 4 | alpha_m_P0 | 0 | 0.2926 | 0.154 |
| 5 | alpha_m_xc | -0.1 | 0.1 | -0.00865 |
| 6 | alpha_m_beta | -0.02 | 0.1 | 0.0393 |
| 7 | alpha_z_P0 | -1.3644 | -0.2274 | -0.758 |
| 8 | alpha_z_xc | 0.1462 | 1.3158 | 0.731 |
| 9 | alpha_z_beta | 0.083 | 0.747 | 0.415 |

These are the original nine-parameter **generation bounds**, not extrema measured
from samples and not the slightly narrower bounds used in some older SBI runs.
For a fair normalized-RMSE comparison, the analysis must use the same saved bounds.
The fixed profile slopes remain alpha=1 and gamma=-0.3, with no mass/redshift
scaling for those two slopes, as in the existing Battaglia12 generator.

`designs/two_param.csv` is the confirmed first 32,768 data rows of
`battaglia_sobol_P0_beta_524288.csv`. `designs/nine_param.csv` is the first 32,768
data rows of `battaglia_sobol_1048576.csv`. **Do not independently sort them.**
These are separate Sobol designs, not row-by-row matched P0/beta values between
the two datasets. Source and derived-file SHA256 hashes are in `designs/provenance.json`.

Row 1 means the first data line after the header. `sobol_global_row` is one-based
and includes `sequence_offset`; use CSV `iloc[sobol_global_row - 1]` in the
original full design when using these shipped prefix tables at offset 0.

To change priors or design size, edit `config.json`, then run:

```bash
python3 make_designs.py --output designs_new --seed 42
```

Set `design_dir` to `designs_new` and choose a **new output root**. The optional
generator needs SciPy. The supplied tables need only NumPy and are already ready
to run. A new SciPy version/seed/design dimension may produce a different design;
the shipped tables are the reproducible reference. Do not regenerate them for
the default run. Offsets must be nonnegative multiples of the block size.
Physical positivity and line-of-sight convergence checks remain enabled. The
old hard-coded Julia prior does not override the bounds in `config.json`.

### Larger datasets with the original Sobol sequence

`config_524288_all_noise.example.json` is a complete ready-to-select configuration
for 524288 rows per design with baseline/goal and deproj0/2. Activate it only in
a separate run folder and use a new output root; `config.json` is unchanged by default.

Set `n_rows` to 524288 and `sequence_offset` to 0. To retain the EXACT prefix
of the shipped designs, obtain both original full CSVs and run:

```bash
python3 make_designs.py --output designs_524288 \
  --source-two-param /path/to/battaglia_sobol_P0_beta_524288.csv \
  --source-nine-param /path/to/battaglia_sobol_1048576.csv
```

Set `design_dir` to `designs_524288` and use a new `OUTPUT_ROOT`. Without source
options, `make_designs.py` creates a NEW scrambled Sobol design: do not mix it
with the shipped sequence. For a further 32k block use `n_rows=32768` and
`sequence_offset=32768` with the original source CSVs. Blocks carry hashes and
offset metadata; a mismatched offset is rejected. For newly generated designs,
extending N preserves the prefix with the same seed, SciPy version, dimension
and priors. Changing worker count does not change seeds. Use separate output
roots for separately sized runs.

### Other noise products

These `config.json` entries enable all four products:

```json
"noise_cases": ["baseline", "goal"],
"deprojections": [0, 2],
"default_product": "baseline_deproj0"
```

For goal deproj2 only, use `["goal"]`, `[2]`, and `"goal_deproj2"` respectively.
The code paints one signal map per parameter row, then generates the selected
Cartesian product of cases and deprojections. Instrumental noise is independent
between products as well as rows. These are separate mock configurations, NOT
a joint model of correlated ILC outputs from the same multifrequency maps.

## Noise streams: the important correction

For mode m and one-based global row g:

```text
noise_seed = base[m] + 65536 * (g - 1)
split_seed = noise_seed + 10000*(deprojection+1) + case_offset + split
case_offset = 100 for baseline, 200 for goal
split = 1 or 2

base[two_param] = 1000000
base[nine_param] = 281474977710656
mask_seed = 12345 for every row in both datasets
```

These are the actual formula and offsets in the bundled Julia simulator. A
stride of ONE reuses the previous row's split2 as the next row's split1. TWO
fixes adjacent baseline0 rows but still collides across products: baseline/goal
offsets differ by 100, and deproj0/2 by 20000. The stride of 65536 reserves a
disjoint block for every row. Separate mode namespaces allow up to 2**32 global
rows each. Do not change the stride or seed bases. All **131072 split seeds**
in the default run are unique. The preflight also verifies 8388608 seeds for
524288 rows per mode and all four products without a large seed allocation.
Adding/reordering products or changing N leaves existing row seeds unchanged.
This revision changes realizations compared with the old bundle: use a new
output root. Each call constructs a
fresh `MersenneTwister(split_seed)` and passes it explicitly to `Healpix.synalm`.
Different seeds provide separate pseudorandom streams; they are not a mathematical
proof of stochastic independence, so the supplied small-map runtime test also
checks reproducibility and that distinct seeds produce different maps.

The worker strips inherited simulator environment overrides before launching
Julia: the older Julia helpers prioritize environment variables over CLI flags.
The reported mask/noise seeds must match the request before a row is accepted.
It also reads back the actual nine pressure parameters from the completed Julia
run and compares them with the labelled CSV row before writing a completion marker.
Beam width and the ring-locked painter are checked too. `safe_paint.jl` adds
per-ring locks to prevent overlapping halos losing simultaneous pixel updates,
without 26 copies of the full-sky map. The physical profile kernel is unchanged;
parallel summation order can still vary at floating-point roundoff level.

## Physics and observable conventions

The simulator paints the Battaglia pressure profile onto the **same fixed halo
catalogue** for every row. The HDF5 dataset `halo_mass_m200c` is interpreted as
Msun/h and divided by h=0.68 before the physical mass cut M200c >= 1e12 Msun.
This matches the supplied HalfDome reader; do not substitute a catalogue with
different mass or position units. Cosmology: Omega_b=0.049, Omega_c=0.261.
The profile and catalogue treatment are copied from the existing generator.

The maps used for the observable are

```text
map_A = mask * (beam_smoothed_y(theta) + noise_A)
map_B = mask * (beam_smoothed_y(theta) + noise_B)
C_ell = cross_anafast(map_A, map_B), lmax=7979, niter=0
```

- NSIDE=4096; Gaussian FWHM=2 arcmin applied to the signal once.
- One seeded apodized spherical-cap mask: support fsky=0.4, apodization=60 arcmin.
  This is a fixed idealized mask, not an actual SO survey footprint.
- The second noise-table column is deproj0, the fourth is deproj2. Input is C_ell,
  not D_ell. Native noise support is ell=80..7979, zero outside that range only
  for harmonic-map generation. The supplied N_ell is applied to **each split**,
  exactly as in the original generator. No extra factor of two is introduced.
  The user confirmed this per-split interpretation for this handoff. If this
  table is instead to represent a final coadded survey map, a split-noise
  convention must be chosen explicitly; that would change the forward model.
- This is the masked pseudo-spectrum: no fsky correction, mask deconvolution,
  extra noise-beam convolution, or post-generation signal rescaling is added.
- Independent cross noise has zero ensemble mean noise bias, but nonzero
  signal-noise and noise-noise variance. Individual cross spectra may be negative.
- Signed C_ell and signed D_ell are preserved. The combiner computes
  D_ell = ell(ell+1)C_ell/(2 pi), then weighted averages with weights 2ell+1 in
  Delta-ell=200 bins on ell=80..7979 (40 bins). No floor, log10 or asinh is applied
  at generation; fit any later asinh/PCA/MOPED transform on training data only.

This changes instrumental-noise realizations, **not the halo lightcone/cosmic
realization**. The two-parameter dataset conditions on seven fixed parameters;
the nine-parameter dataset can support marginalization over those seven. Their
posterior widths therefore need not agree even with identical training counts.

## Installation and paths

The archive includes simulator/helper sources, a vendored XGPaint source snapshot
with its license, pinned Julia Project/Manifest files, and both noise tables.
Goal generation is enabled only when `noise_cases` includes `goal`.

**Not included:** the approximately 15.4 GB `lightcone_100.hdf5`, Julia executable,
or downloaded Julia package/artifact binaries. The collaborator must have the
original catalogue and permission to access it. Dependencies must be installed
where compute nodes can read them; initial installation needs network access.

1. Extract the archive, enter this folder, and verify `sha256sum -c SHA256SUMS`.
2. Install/use Julia **1.12.2** for the supplied dependency lockfile and RNG
   reproducibility. Python >=3.8 with NumPy is enough for generation/combination.
   SciPy is needed for new Sobol designs and the Sobol-extension unit test;
   Matplotlib is needed for diagnostic plots.
3. Edit `cluster.env`: `HALFDOME_PATH`, `OUTPUT_ROOT`, `JULIA`, `PYTHON`, and the
   PBS queue/resources. Use an absolute, shared scratch path for output.
4. Do installation/precompilation once, not in every worker:

```bash
source cluster.env
"$JULIA" --startup-file=no setup_julia.jl
"$PYTHON" -m unittest -v test_generation.py
"$JULIA" --startup-file=no --project=vendor/XGPaint check_runtime.jl
"$PYTHON" check_simulator_cli.py --julia "$JULIA"
"$PYTHON" diagnose_noise.py --julia "$JULIA"
"$PYTHON" generate.py check
```

The vendored active project guarantees that the simulator does not accidentally
load another installed XGPaint. A different Julia/dependency version can change
random realizations even with identical seeds and needs renewed validation.
For non-default designs, pass the design directory to `check_runtime.jl`.
`diagnose_noise.py` writes five PNG/PDF plots and a numerical report in
`validation_plots/`. The noise tests use NSIDE=128 and lmax=255 by default.
Full native input curves are shown, but the measured noise tests cover only
that reduced range. They do not validate production-resolution halo mocks.

## PBS runs and resuming

The scripts target PBS Professional/OpenPBS, not Slurm. Default resources are
`mini`, 26 CPUs, 128 GB, 23:59 walltime. Map generation needs much more memory than
NPE training. Adjust to the collaborator's queue limits after the smoke job.
Workers use 26 Julia threads but one BLAS/OpenMP thread to avoid nested oversubscription.
For another scheduler, the same work can be launched directly with
`python3 generate.py work --worker 0 --workers 20`; assign each process a distinct
worker index 0..19 and the same shared output root. PBS submission is optional.

```bash
bash submit.sh smoke           # 1 job: first row of each dataset; retain outputs
"$PYTHON" generate.py status   # after the smoke job; verifies hashes/seeds/shapes
DRY_RUN=1 bash submit.sh wave  # inspect the proposed qsub commands
bash submit.sh wave           # 20 separate worker jobs; at most 5 active by default
```

Wait for the wave to finish. Then:

```bash
"$PYTHON" generate.py status
bash submit.sh wave           # continue missing rows, WITHOUT repeating completed rows
```

There are no PBS arrays. Worker assignment is deterministic and balanced between
datasets. Lock files prevent duplicate simultaneous work on a row. Completed
rows have atomic `complete.json` markers with theta, global/local identity,
seed values, output hashes, command and runtime. Existing output whose inputs
or code changed is rejected; use a new output root instead of silently mixing runs.
Missing/corrupt rows are never silently dropped or relabelled.

**20 jobs is not a promise of completing 64k profiles in 24 hours.** At 240 seconds
per profile, 65,536 profiles take about 4,369 node-hours: about 9.1 days with
20 continuously active jobs, or 36.4 days with only 5, before queue/overhead costs.
Measure actual runtime with the smoke job. By default a worker stops before its
walltime margin and the same wave command resumes its remaining work. Set
`MAX_ACTIVE_JOBS=20` only if the collaborator's scheduler permits it. Increasing
`N_WORKERS` changes scheduling, not the row seeds or scientific result.

Logs are streamed to `$OUTPUT_ROOT/logs/worker_<id>_<PBS_JOBID>.log` and individual
row logs live beside the raw spectra. Use `tail -F` on either. Job IDs are stored
in `jobs_<wave-or-smoke>_<timestamp>.txt` and linked by `latest_jobs.txt`.
Do not modify `config.json` or source files while a wave is running.

## Outputs and final checks

After status reports 32768/32768 for BOTH datasets:

```bash
"$PYTHON" generate.py combine
```

Each of `$OUTPUT_ROOT/two_param/prepared` and `nine_param/prepared` contains:

- `dataset.npz`: theta (N,2 or N,9), theta_full (N,9), prior bounds, parameter
  names, x and x_no_noise (N,40), ell/bin vectors, Sobol row IDs and all seed labels.
  Each selected product also has `x_<product>` and `noise_split_seeds_<product>`.
  `x` aliases `default_product`. Theta stays float64 to avoid rounding a boundary
  row outside the saved prior.
- `cl.npy`, `cl_no_noise.npy`: float32 (32768,7900), ell=80..7979, load via mmap.
  Additional products use `cl_<product>.npy`; metadata lists these filenames.
- `complete.json`: metadata and hashes of all final files. Do not use a combined
  dataset without this marker; it is removed before recombination starts.

Original per-row float64 spectra contain ell=0..7979. Combined and raw outputs
need roughly 13 GB across both datasets, excluding logs and transient caches.
No full-sky maps are stored; per-row interpolator caches are temporary.

```python
from pathlib import Path
import numpy as np
p = Path("/your/scratch/so_32k_independent_noise/two_param/prepared")
with np.load(p / "dataset.npz", allow_pickle=False) as z:
    print(z["theta"].shape, z["x"].shape, z["param_names"])
    assert z["x"].shape == (32768, 40)
    assert len(np.unique(z["noise_split_seeds"])) == 65536
cl = np.load(p / "cl.npy", mmap_mode="r")
assert cl.shape == (32768, 7900)
```

The prepared data do not contain an SBI-trained estimator or a Battaglia12
observation. Those are separate later steps. Keep the seed metadata and fit
the training/observation preprocessing consistently in the analysis pipeline.
An estimator trained on the earlier fixed-noise data must not be reused as an
independent-noise estimator; train new NPE models on these newly generated pairs.

and exact 524288-row extensions together, pass `--sizes 32768 524288` plus
`--two-param-csv` and `--nine-param-csv` with the original full source CSVs.
